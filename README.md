# Welcome Holdings LTD — website

A single-page static site for Welcome Holdings LTD, a gaming holding group.

## Running it

No build step and no dependencies. Open `index.html` in a browser, or serve the folder:

```
python -m http.server 8000
```

## Structure

Everything lives in `index.html` — markup, styles and the theme toggle. External resources are limited to two Google Fonts (Fraunces, Inter).

Sections: hero · about · how we acquire · commitments to players.

## Notes

The site carries no figures, studio names or contact details. Those were removed on purpose — add them only once they can be backed up.
